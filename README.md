# Awami Foods Showcase

Build a Premium Showcase Website for Awami Foods

1. ROLE

Act as a senior UI/UX designer, frontend engineer, brand designer, and conversion-focused web developer.

Build a polished, production-quality showcase/demo website for a real local bakery called Awami Foods (عوامی) in Karachi, Pakistan.

IMPORTANT:

This is initially a concept/demo website that will be shown to the bakery owner.

The goal is NOT to pretend that every piece of information on the website has been officially confirmed.

The goal is to create a visually impressive website that demonstrates what Awami Foods' professional online presence could look like.

If the bakery owner likes the concept, the website will later be updated using their official logo, photographs, menu, prices, products, business story, social media, WhatsApp ordering, delivery information, etc.
